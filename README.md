# A landing-page experiment

What would make a busy person stop scrolling and consider a fitness-coaching program?

This is my AI-assisted attempt at that: offer copy, common objections and an application form, all in one HTML file. I approached it as a marketer exploring the message and the journey; AI tools supported the build.

## Try it

Download [index.html](index.html) and open it in your browser. No install or API keys needed. [See the form](docs/application-preview.png).

Built with HTML, CSS and plain JavaScript, plus Google Fonts.

**Prototype only:** the form checks inputs and shows a local confirmation. It doesn't send or save applications. Testimonials, weight-loss claims and limited-place messaging are unverified example copy.

The next thing I'd test: does a shorter form make it easier to get started without losing useful context? No results yet; that's a proposed experiment.
